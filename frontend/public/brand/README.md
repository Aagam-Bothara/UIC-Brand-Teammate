# UIC brand marks

Official University of Illinois Chicago marks, as published on https://brand.uic.edu/visual-identity/logos/
(managed by UIC Strategic Marketing and Communications).

- `uic-logo-primary.png`: full-color university logo (use on white/light backgrounds only).
- `uic-circle-mark.png`: full-color circle mark (internal audiences; pair with the typeset name).

Usage rules (https://brand.uic.edu/visual-identity/logos/): use only approved color variations, never
recolor, stretch, rotate or add effects, keep the required clear space, and keep sufficient contrast.
These are UIC trademarks: confirm usage with smcs@uic.edu before any public/external deployment.
