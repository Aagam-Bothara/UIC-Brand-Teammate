## Rule-engine gaps (for Workstream 2)

The rule engine has no rule for 25 of the 36 dataset issue types planted here:

- **Visual and design issues (need the rendered file or image analysis, Phase 2):** Flashing content detected; Incorrect UIC logo version; Low color contrast ratio; Non-standard fonts detected; Small font size (<12pt); Unapproved department logo; Unauthorized stock photography; Wrong brand colors used.
- **Document structure and media issues (need HTML/PDF/video input, not plain text):** Form fields unlabeled; Missing language attribute; Missing official template; No heading hierarchy; No keyboard navigation support; No skip navigation; PDF not tagged for screen readers; Table without headers; Video missing captions.
- **Absence and semantic checks (possible as new text rules or LLM checks):** Broken hyperlinks; Duplicate content detected; Missing UIC tagline; Missing call-to-action; Missing contact information; Missing disclaimer text; Missing subject line (email); Outdated statistics referenced.

Ideas for the absence and semantic group: required-element checks per channel (subject line for email, contact line, call to action, accommodation or disclaimer statement, tagline), a URL syntax check (`https//`, spaces, misspelled paths) for broken links, a duplicate-sentence check, a stale-year check for statistics ("In 2012, ..."), and a passive-voice heuristic. A spelling checker would catch typos like "recieve"; today only doubled words are caught.

Issue types with a rule that still missed some planted instances:

- **Brand voice inconsistency** (2/3): hype without a style error ("the coolest nursing school... nobody does it better") has no rule.
- **Inconsistent date formats** (2/5): content-005 and content-014 catch ordinals and month abbreviations, but not numeric dates (`8/20`, `10/23`) mixed with written dates.
- **Missing alt text on images** (0/1): access-004 only matches Markdown or HTML images, not a text placeholder such as `[Image: photo.jpg]`.
- **Passive voice overuse** (1/2): tone-005 only matches set bureaucratic phrases ("it is recommended that"), not general passive voice ("will be led by").
- **Spelling/grammar errors detected** (1/2): content-007 catches doubled words only; there is no spelling check ("recieve").
